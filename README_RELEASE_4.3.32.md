# Powerline Web — Release 4.3.32

- حذف نشانگر رنگی کنار نام خطوط در پنجره انتخاب خطوط نقشه برای ظاهر تمیزتر.
- استانداردسازی Toastهای اطلاع‌رسانی، هشدار، موفقیت و خطا با ظاهر یکپارچه و آیکون متناسب.
- حفظ نمایش Toastها در مرکز صفحه و با z-index بالا.
- ویرایش گروهی دکل‌ها از endpoint دسته‌ای `/towers/bulk-update` با بسته‌های حداکثر ۱۰۰تایی.
- ساختار دکل و کد نوع دکل در ویرایش گروهی از جداول مرجع انتخاب می‌شوند.
- نسخه پروژه به 4.3.32 ارتقا یافت.
