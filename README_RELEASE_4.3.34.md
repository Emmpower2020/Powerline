# Powerline Web v4.3.34

## اصلاح نماد دکل‌ها روی نقشه

- شکل دکل‌ها اکنون بر اساس `tower_structure` تعیین می‌شود، نه `tower_type`.
- مشبک فلزی = مربع
- تیر چوبی = مثلث
- تیر بتنی = دایره
- تلسکوپی فلزی/بتنی = لوزی
- رنگ نمادها بر اساس ولتاژ خط حفظ می‌شود.
- برای ساختار ناشناخته دیگر از ضربدر سفید استفاده نمی‌شود و نماد دایره‌ای خنثی نمایش داده می‌شود.
- راهنمای نقشه با همین ساختارهای واقعی همگام شد.
