# Powerline Web v4.3.18

## تغییرات

- شمارنده تعداد ردیف‌های انتخاب‌شده بعد از Settings نمایش داده می‌شود.
- برای انتخاب کدهای دیسپاچینگ فرم ثبت/ویرایش خط، دکمه «تأیید کدهای انتخاب‌شده» اضافه شد.
- خط جدید بدون مسیر GIS دیگر با `NULL` در `geom` ثبت نمی‌شود و از `LINESTRING EMPTY` استفاده می‌کند.
- پراکسی Next.js دیگر پاسخ JSON با وضعیت 5xx را به‌اشتباه «سرور در دسترس نیست» تبدیل نمی‌کند؛ خطای واقعی API/دیتابیس مستقیماً به رابط کاربری می‌رسد.
- خطای درج دکل در endpoint به‌صورت کنترل‌شده ثبت و گزارش می‌شود.
