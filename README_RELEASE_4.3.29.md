# Powerline Web v4.3.29

- جداول مرجع «انواع ساختار دکل» و «انواع کد دکل» اضافه شد.
- ستون `foundation_type_code` در دکل‌ها به `tower_type_code` مهاجرت می‌کند.
- ستون `tower_structure` در خطوط مرجع نهایی ساختار دکل است.
- ساختار خط بعد از ثبت دکل‌ها از پرتکرارترین `tower_structure` دکل‌های فعال همان خط محاسبه و قفل می‌شود.
- فرم دکل با مرجع‌های جدید کار می‌کند و عنوان «سرپرست خط» ساده‌سازی شده است.
- فرم خط، ساختار دکل را از جدول مرجع دریافت می‌کند و پس از وجود دکل‌ها غیرقابل ویرایش است.
