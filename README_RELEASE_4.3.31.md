# Powerline Web v4.3.31 — Tower table & map stability fixes

این نسخه بر پایه نسخه 4.3.30 ساخته شده و چند ایراد واقعی شناسایی‌شده در بازبینی پروژه را اصلاح می‌کند.

## اصلاحات
- عنوان ستون نمایش `tower_code` در جدول دکل‌ها به «نام دکل» تغییر کرد؛ دیتابیس فعلی فیلد مستقل `tower_name` ندارد و نام نمایشی دکل از همان شناسه/کد دکل استفاده می‌کند.
- نام خطوط روی نقشه دیگر در زوم پایین مخفی نمی‌شود و تا وقتی `showLineLabels` فعال است نمایش داده می‌شود.
- فضای امن برچسب‌های خطوط با توجه به باز بودن پنل انتخاب خطوط تنظیم شد تا نام‌ها زیر پنل سمت چپ نروند.
- ابزار «موقعیت جغرافیایی» از Geolocation API مستقیم مرورگر استفاده می‌کند و خطاهای مجوز، HTTPS، نبود GPS و timeout را با پیام واضح نمایش می‌دهد.
- اندازه کنترل‌های نوار ابزار نقشه برای جبران حذف کنترل قدیمی بزرگ‌تر شد.
- باگ حذف گروهی دکل‌ها که از متغیر تعریف‌نشده `$linesCache` استفاده می‌کرد اصلاح شد؛ اکنون خطوط درگیر قبل از حذف شناسایی و بعد از حذف مجدداً sync می‌شوند.
- در حذف/غیرفعال‌سازی آخرین دکل دارای ساختار، مقدار قدیمی `lines.tower_structure` پاک می‌شود.
- هنگام انتقال یک دکل به خط دیگر، ساختار غالب هم خط قدیم و هم خط جدید مجدداً محاسبه می‌شود.
- import انبوه اکنون شناسه دکل ناموجود را به‌عنوان خطا گزارش می‌کند و خطوط قدیم/جدید تغییرکرده را برای sync در نظر می‌گیرد.
- خطای UNIQUE هنگام ویرایش دکل به پاسخ 409 و پیام قابل‌فهم تبدیل شد.
- ناسازگاری انتخاب همه در جدول اصلاح شد: چک‌باکس هدر فقط صفحه جاری را انتخاب می‌کند و دکمه «انتخاب همه» همچنان تمام نتایج فیلترشده را انتخاب می‌کند.
- چند خطای TypeScript در بخش فیلتر جدول از طریق type narrowing صریح اصلاح شد.

## تست
- تمام فایل‌های PHP پروژه با `php -l` بررسی شدند و خطای syntax ندارند.
- اجرای TypeScript در محیط فعلی به دلیل نصب نبودن وابستگی‌های npm کامل نشد؛ بنابراین build نهایی Next.js در این محیط قابل تأیید نیست.
