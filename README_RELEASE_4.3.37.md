# Powerline Web v4.3.37

## اصلاح مرتب‌سازی جداول

- جدول خطوط: سطح ولتاژ با ترتیب ۴۰۰، ۲۳۰، ۱۳۲، ۶۳، سپس نام خط و در حالت تساوی کد خط.
- جدول دکل‌ها: سطح ولتاژ، سپس نام خط، کد خط و در نهایت شماره دکل از کوچک به بزرگ؛ بنابراین دکل‌های هر خط کاملاً پشت‌سرهم می‌مانند.
- جدول مدارها: سطح ولتاژ، سپس نام مدار و در حالت تساوی کد دیسپاچینگ.
- دکمه «تنظیمات و جابه‌جایی ستون‌ها» و Drag & Drop ترتیب ستون‌ها حفظ و دوباره به‌صورت مشخص در نوار ابزار در دسترس است.
