# Powerline Web — Release 4.3.33

## اصلاحات
- اصلاح fallback ستون کد نوع دکل در API و جلوگیری از فرض صوری وجود `tower_type_code`.
- اصلاح همگام‌سازی `lines.tower_structure` هنگام حذف/غیرفعال شدن آخرین دکل دارای ساختار.
- مقاوم‌سازی migration نوع دکل در برابر مقدار NULL/خالی.
- حذف دکمه مستقل «انتخاب همه» از نوار ابزار؛ چک‌باکس ابتدای جدول این وظیفه را انجام می‌دهد.
- حذف دستگیره عمودی کنار نام ستون‌ها در پنل تنظیم ستون‌ها، بدون حذف قابلیت Drag & Drop.
- بهبود ظاهر اعلان‌های خطا، هشدار، موفقیت و اطلاعات با عرض کمتر و نمایش مناسب‌تر.
- جایگزینی `window.alert` ویرایش چندردیفی با اعلان داخلی برنامه.
