# Powerline Web v4.3.35

## اصلاحات رابط کاربری و کمبوباکس

- پنل فیلتر مقادیر ستون‌ها: نوار اسکرول مخفی شد و متن‌های طولانی هر مقدار حداکثر در دو خط نمایش داده می‌شوند.
- در تمام `SearchableSelect`ها دکمه × پاک‌کردن حذف شد.
- گزینه «نامشخص» به ابتدای همه کمبوباکس‌های جستجوپذیر اضافه شد؛ انتخاب آن همان مقدار خالی قبلی را به فرم برمی‌گرداند و مقدار جدیدی در دیتابیس ایجاد نمی‌کند.
- سایر منطق انتخاب، جستجو و گزینه‌های موجود حفظ شده است.
